Aunt Harriot

You bring your own Anthropic API key Harriot brings the git know-how.

Enter into the workspace Read the full story

Think of Harriot as the domesticated cousin of Christopher's other Claude Code agents — same underlying know-how, built to run for someone who isn't Christopher. You log in with a one-time link, add your own API key, and describe what you want changed in plain English. Harriot makes the edit on a branch of her own; Christopher reviews it before anything goes live.
