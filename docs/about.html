The mechanics

Getting in

No password to invent. You'll enter your email; if it's on Christopher's invite list, you get a one-time login link. After that, you add your own Anthropic API key — that's what pays for the actual thinking Harriot does on your behalf, separate from Christopher's own Claude subscription. The invite list is the real access boundary, not the API key — the key just means whoever's using Harriot is covering their own usage.

Making a change

You describe what you want in plain English. Harriot reads the relevant files, proposes a specific change, and — once you confirm it looks right — pushes it to a branch of her own (named after you and the task, so it's always clear who asked for what). She never touches main directly. Christopher reviews the resulting pull request and merges it; that review step is the actual safety net, not a courtesy.

What Harriot can touch

Whichever repos you're specifically invited to — for you, that's iamoneself and david-amaringo, nothing else. Harriot's own git identity (a scoped GitHub App or personal access token — not decided yet) is restricted to exactly those repos, so even a mistake or a compromised session can't reach anywhere else in Christopher's account.

Where your API key lives

Entered after login, never before, and never written into any file that gets committed to git. Whether it's encrypted-at-rest or kept session-only is still being decided — either way, it's never logged and never sent back to your browser after you first enter it.

FAQ

Do I need a GitHub account?

No. That's the whole point — Harriot handles git and GitHub on your behalf, on a branch scoped to you, and Christopher merges it. You never need to touch either directly.

What can't Harriot do?

She can't push straight to main, can't touch any repo you weren't specifically invited to, and can't merge her own pull requests — every change waits for Christopher's review. If she's ever unsure whether something's in scope, the plan is for her to ask rather than guess.

What does this cost me?

Whatever your own Anthropic API usage runs — Harriot's thinking is billed to the key you provide, not to Christopher's subscription. There's no separate fee for Harriot herself.

What if I don't like a change she made?

Nothing goes live without Christopher reviewing it first, so a bad suggestion never reaches the real site. You can also just say so in the same conversation and ask for something different before it's even proposed as a pull request.

Is any of this live yet?

Not the actual workbench — the workspace preview is a mock showing the shape it'll take. This site and the groundwork behind it are real and already built; see the roadmap above for exactly what's left.
